# 🐘 Mastodon 内容监听机器人

一个基于 Mastodon API 实现的自动化内容监听与响应机器人，支持用户通过自定义格式请求，抓取目标平台内容（原为 Twitter），并将结果以私信形式返回。项目最初部署于本人自建 Mastodon 实例 `ahec.world` 上，用于探索 API 自动化交互与跨平台集成的可能性。

---

## ✨ 项目特色

- 🎯 **实时监听本地时间线**：基于 Mastodon 的 `stream_local` 接口监听用户发帖。
- 📡 **自定义指令解析**：用户可使用 `-uid`, `-tag`, `-word` 等参数触发内容抓取。
- 🌍 **跨平台内容聚合**：原始版本支持从 Twitter 抓取内容（使用 Scweet 库），现已支持替换为 Reddit。
- 🌐 **多语言支持**：集成翻译模块，自动将抓取内容翻译为用户语言（可选）。
- 🛰️ **私信方式回应用户**：抓取成功后将信息通过 Mastodon 私信返回。
