# 🐘 Mastodon 内容监听机器人

一个基于 Mastodon API 实现的自动化内容监听与响应机器人，支持用户通过自定义格式请求，抓取目标平台内容（原为 Twitter），并将结果以私信形式返回。项目最初部署于本人自建 Mastodon 实例 `ahec.world` 上，用于探索 API 自动化交互与跨平台集成的可能性。

该项目最初作为作者用于测试 Mastodon 私有服务器功能的实验工具，后逐步发展为可扩展的内容自动抓取与播报系统。重点探索以下方向：
+ API 自动化监听机制
+ 内容抓取与指令式交互的结合
+ 自定义平台与现有社交平台的集成

项目于2022年开启，目前已中止。功能和扩展内容将转移至reddit抓取及telegram播报bot中。
